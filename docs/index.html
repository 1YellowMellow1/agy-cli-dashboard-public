ARCHITECTURE & COMPARISON

Which Antigravity Tool for Which Purpose?

The official Antigravity technology stack exists in three main flavors. Compare strengths and tradeoffs at a glance.

TERMINAL NATIVE

Google Antigravity CLI

Official, minimalist command-line interface (agy) for the Windows console or Linux/Mac terminals.

  • + Ultra-minimalist resource footprint in terminal (< 35 MB RAM)
  • + Ideal for CI/CD pipelines and headless script automation
  • + Full access to official slash commands and MCP tools
  • − Completely blind: No AI Co-Browser for web apps, DOM maps, or UI tests
  • − Session amnesia: No cognitive long-term memory for learned lessons
  • − No automatic safety guardrails ('go' approval gate / auto-reflection)
  • − No automated ignore triad to protect against token waste
STANDALONE IDE

Antigravity Desktop (IDE)

Standalone, cloud-bound development environment based on modern web/Electron technologies.

  • + Full graphical IDE experience with integrated code editor
  • + Integrated cloud synchronization and workspace management
  • + Beginner-friendly chat interface for visual developers
  • − Noticeably higher RAM footprint (Electron runtime ~500 MB – 1.2 GB RAM)
  • − No interactive Co-Browser with CDP control and accessibility tree
  • − No programmatic 'go' safety gates or 21 one-click toolbar macros
  • − Strict editor replacement rather than a lightweight companion for your setup
NATIVE WINDOWS COCKPIT (COMMUNITY)

AGY CLI Dashboard

Native WinUI 3 & .NET 10 cockpit designed as a visual companion on top of your local Antigravity CLI.

  • + True Native Windows 11: WinUI 3 & .NET 10 (< 100 MB RAM, cold start < 0.8s, ConPTY DirectX)
  • + Integrated AI Co-Browser: Split-screen with CDP (Port 9222), Accessibility Tree & Human Takeover
  • + Cognitive Long-Term Memory: Automated 2-tier knowledge base eliminates session amnesia
  • + Strict Safety Guardrails: Approval gate ('go'), deployment gate ('deploy') & Auto-Reflection
  • + Context Hygiene: Automated ignore triad saves up to 80% context tokens
  • + 21 One-Click Quick Actions: Toolbar macros for audits, Git safety, cleanups & DE/EN toggle
  • * Requires the installed Antigravity CLI (agy) on the host system
